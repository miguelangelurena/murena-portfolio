# Rediseño responsive / Responsive redesign

## Cambios
- Barra superior móvil compacta con identidad y selector EN/ES.
- Navegación flotante inferior estilo app con Inicio, Experiencia, Proyectos y Contacto.
- Tarjetas de experiencia responsivas: títulos, fechas y etiquetas sin romper palabras.
- Hero en formato tarjeta, descargas de CV optimizadas para pantallas táctiles.
- Sección de contacto integrada para la navegación móvil.
- Ambos idiomas y ambas páginas del caso de estudio conservados.

## Publicación
Sube los archivos del proyecto manteniendo su estructura. En GitHub Pages / hosting estático,
asegúrate de conservar index.html y las rutas en Assets/. No necesitas dependencias adicionales.

## Pruebas recomendadas
Probar 320, 375, 390, 430 y 768 píxeles, cambios de idioma, navegación inferior,
scroll y descargas de CV. El menú móvil aparece hasta 700 px.
