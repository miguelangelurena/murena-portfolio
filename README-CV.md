# CV downloads / Descargas de CV

This site is static HTML/CSS/JS. Its home page includes two prominent download links:

- `Assets/Miguel_Urena_CV_EN.pdf` — English CV
- `Assets/Miguel_Urena_CV_ES.pdf` — Currículum en español

## Publish / Publicar

Upload the **contents** of this folder to your existing hosting provider (or copy these changes to your GitHub repository and deploy from it). Preserve the `Assets/` directory and filenames. No additional dependencies or server-side code are required.

## Replace CVs later / Actualizar los CV

Export the updated PDFs, replace the two files above **using exactly the same filenames**, and redeploy. The website links will continue working. Note that browsers or CDNs may cache old PDFs; clear/invalidate cache when replacing files if necessary.

The contact email was aligned with the Gmail address on the CVs. The homepage no longer links to the old resume PDF. The complete project package omits that old PDF; if applying only the update package, you may manually delete `Assets/Miguel_Urena_Resume.pdf` from your existing site.
