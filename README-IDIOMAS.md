# Portfolio bilingüe — Miguel Ureña

Este paquete es una versión completa del sitio estático, con **inglés y español** en todas sus páginas.

## Archivos principales
- `index.html` — página principal (inglés, ruta `/`).
- `index-es.html` — página principal (español, ruta `/index-es.html`).
- `tesoria-case-study.html` — caso práctico de Tesoria (inglés).
- `tesoria-case-study-es.html` — caso práctico de Tesoria (español).
- `Assets/Miguel_Urena_CV_EN.pdf` y `Assets/Miguel_Urena_CV_ES.pdf` — versiones descargables de CV.

## Publicación
Sube **el contenido de esta carpeta** al repositorio que publica `miguelurena.dev`, respetando las rutas. El selector `EN / ES` en la navegación lleva a la versión traducida y el idioma se mantiene al visitar el caso práctico de Tesoria y regresar al portafolio. No requiere frameworks, compilación ni herramientas adicionales.

## Modificaciones futuras
El contenido de cada idioma es HTML independiente (más fácil de indexar en buscadores). Para cambios en proyectos, experiencia y textos, actualiza ambos archivos de cada página. Los CV pueden reemplazarse sin cambiar el código si conservas los nombres de archivo.

**Nota:** los enlaces en vivo del portafolio no se actualizan hasta desplegar estos archivos a tu alojamiento web.
